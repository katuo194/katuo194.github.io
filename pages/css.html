1. ファイル構成とCSSの読み込み

一般的なファイル構成

CSSを適用するには、HTMLファイルとは別にCSSファイルを作成し、HTML内で読み込むのが最も一般的な方法です。

フォルダ構成例
プロジェクトフォルダ/
 ├── index.html
 ├── css/
 │    └── style.css
 └── images/
      └── logo.png

HTMLの <head> 内で以下のように読み込みます。

<link rel="stylesheet" href="css/style.css">

2. CSSの基本ルール（構文）

セレクタ・プロパティ・値

CSSは「どこの」「何を」「どうする」という3つの要素で構成されます。

  • セレクタ: デザインを適用するHTMLタグやクラス名
  • プロパティ: 変更したいデザインの種類
  • 値: どのように変更するか
構文の例
h1 {
    color: #2c3e50;
}

3. 特定の場所だけデザインを変える「クラス（class）」

class（クラス）とは？

すべての <button> ではなく、「このボタンだけ赤くしたい！」という場合があります。そんな時にHTML側につける「名札」が class です。

  • HTML側: タグの中に class="好きな名前" を書きます。
  • CSS側: 名前の先頭に必ず .（ドット） をつけて指定します。
  • 同じページ内で、同じclass名を何度でも使い回すことができます。
実行結果の比較

【HTMLの書き方】

<button>普通のボタン</button>
<button class="btn-special">特別なボタン</button>

【CSSの書き方】 ドットを忘れないように注意！

/* classを指定するときは先頭に「.」をつける */
.btn-special {
    background-color: #e74c3c;
    color: #ffffff;
}

4. レイアウトの要「ボックスモデル」

余白のルール

Web上のすべての要素は、四角い「箱（ボックス）」として計算されます。

ボックスモデルの図解
Margin（外側の余白）
Border（境界線）
Padding（内側の余白）
Content（中身） 
.box {
    padding: 20px;      /* 内側の余白 */
    border: 4px solid #000; /* 境界線 */
    margin: 20px;       /* 外側の余白 */
}

5. よく使うCSSコマンド集

Flexbox（横並びレイアウト）

親要素のclassに display: flex; を指定すると、子要素が横並びになります。現代のWebレイアウトで最も使われる手法です。

実行結果（justify-content: space-between;）
Item 1
Item 2
Item 3
.flex-container {
    display: flex;
    justify-content: space-between;
}
