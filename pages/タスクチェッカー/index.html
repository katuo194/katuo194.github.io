自己紹介サイト制作チュートリアル

タスクが完了したら、右下のチェックボックスをクリックして次のステップへ進みましょう。

※前提条件としてVSコードのインストールとそのライブラリであるLive Serverのインストールが必要です。

Step 1: 開発環境の準備

PC上に my-website というフォルダを作成してください。このフォルダの中で作業を行います。作成できたらVS Codeでそのフォルダを開きましょう。

Step 2: HTMLで骨組みを作る

フォルダ内に index.html というファイルを作成し、以下のコードを記述して保存してください。

<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>{名前}のポートフォリオ</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>自己紹介</h1>
    <button id="alertButton">クリックしてね</button>
    <script src="script.js"></script>
</body>
</html>

Step 3: CSSでデザインを整える

次に style.css というファイルを作成し、以下のコードを記述して保存します。

body {
    text-align: center;
    font-family: sans-serif;
    background-color: #f0f8ff;
    padding: 50px;
}
button {
    background-color: #3498db;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 5px;
    cursor: pointer;
}

Step 4: JavaScriptで動きをつける

最後に script.js というファイルを作成し、以下のコードを記述して保存します。

document.getElementById('alertButton').addEventListener('click', () => {
    alert('こんにちは！プログラミングの世界へようこそ！');
});

Step 5: ブラウザで動作確認

保存した index.html をVS CodeのLive Server機能を使ってブラウザで開いてみましょう。ボタンを押してメッセージが出れば完成です！

🎉 お疲れ様でした！初めてのWebサイト構築成功です！ 🎉
